# Lightweight CNN for Activity Recognition
Designing resource-constrained deep learning models for Microcontroller Units (MCU).

### 🔬 Research Highlights
- **Model Compression**: Uses depth-wise separable convolutions and quantization to fit models into KBs of memory.
- **Sensor Fusion**: Processes accelerometer/gyroscope data for real-time Human Activity Recognition (HAR).
- **Embedded AI Focus**: Optimized for low-power edge devices and IoT hardware.

**Tech Stack:** Python, `TensorFlow Lite`.
